# План презентації диплому

## Тема
Розроблення навчальної платформи для набуття практичних навичок full-stack розробки на основі Monorepo-архітектури

## Слайд 1 — Титульний
Тема, ПІБ, керівник, університет.

## Слайд 2 — Проблема
**"Як набути реальний досвід без реального проєкту?"**
- Студент хоче вивчити frontend — але де взяти працюючий backend з API, щоб писати під нього?
- Студент хоче вивчити backend — але як перевірити що його API працює правильно без готового клієнта?
- Існуючі курси: todo-app з mock-даними, без реальної клієнт-серверної взаємодії
- Немає структурованого шляху: що робити першим, що другим, які сценарії покрити
- Ментор коштує дорого і доступний обмежений час

## Слайд 3 — Існуючі рішення не вирішують проблему
**Таблиця порівняння** (з диплому)
- freeCodeCamp — ізольовані вправи у браузері
- Udemy — пасивне відео, студент повторює за інструктором
- The Odin Project — немає готового backend для frontend-студента
- Frontend Mentor — тільки frontend, без API
- LeetCode/HackerRank — алгоритми, не проєктна розробка
- Boot.dev — тільки backend, немає frontend/mobile
- Scrimba — штучне середовище, немає реального проєкту

Жодна платформа не дає: готову інфраструктуру + спринти з реальними продакшн-задачами + AI-ментор через IDE

## Слайд 4 — Наше рішення
**"Навчальна платформа на основі Monorepo"**
- Діаграма monorepo-structure
- Студент обирає напрямок і працює з платформою
- Студенту НЕ потрібно розуміти як працює monorepo, як запускати сервер, вичитувати файли задач
- При використанні розумної IDE (Kiro, Cursor, Antigravity) — AI сам зчитує код і тікети та стає ментором
- Всі вихідні файли (код, тікети, архітектура) потрібні AI в IDE — він їх зчитує і на основі них веде студента
- Продукт = код (інфраструктура) + методика (тікети/спринти). AI-менторство — опціональний бонус завдяки розумним IDE
- Monorepo — технічне рішення під капотом. Бонус: коли студент дозріє, може вивчити цей підхід

## Слайд 5 — Як це працює: сценарій студента
**Діаграма use-case**
- Крок 1: Відкриває розумну IDE з двома папками у workspace: платформа (monorepo) + свій порожній проєкт
- Крок 2: AI в IDE бачить обидва контексти: задачі/код платформи + код студента
- Крок 3: Пише AI: "Я хочу вивчити frontend. Запусти мені backend."
- Крок 4: AI запускає backend, каже що готово
- Крок 5: Пише AI: "Дай мені першу задачу"
- Крок 6: AI видає тікет, пояснює що робити
- Крок 7: Студент реалізує задачу у своєму проєкті, AI допомагає по ходу (бачить і задачу, і код студента)
- Крок 8: Пише AI: "Перевір мій код" — AI порівнює з вимогами тікету і дає фідбек

Вся складність (monorepo, файли тікетів, архітектура) прихована за інтерфейсом IDE. AI одночасно бачить базу знань (платформу) і роботу студента (його проєкт). Використання AI — опціонально, студент може працювати і без нього, читаючи тікети самостійно.

## Слайд 6 — Спринтова модель
**Діаграма sprint-progression**
- Sprint 1: Авторизація (JWT, форми, валідація)
- Sprint 2: Читання даних (API, стани, помилки)
- Sprint 3: Повний CRUD (файли, пагінація)
- Sprint 4: Розширення (пріоритети, редизайн)

**Ключовий акцент:** задачі спринтів — це не абстрактні вправи, а ключові сценарії, які студент зустріне на реальному продакшн-проєкті. Авторизація, CRUD, пагінація, робота з файлами, обробка помилок — це 90% щоденної роботи розробника.

## Слайд 7 — Використання розумних IDE з вбудованим AI
**Діаграма ai-assistant-flow**
- Сучасні IDE (Kiro, Cursor, Antigravity, GitHub Copilot) мають вбудований AI
- Коли студент відкриває нашу платформу в такій IDE — AI автоматично зчитує весь контекст
- AI стає ментором без жодної додаткової розробки з нашого боку
- Студент спілкується з ним як з реальною людиною: просить пояснити, допомогти, перевірити
- Це опціонально — платформа працює і без AI, просто з ним зручніше
- Бонус: студент паралельно вчиться prompt engineering

**"Розумна IDE перетворює нашу кодову базу на персонального ментора — без жодного рядка додаткового коду"**

## Слайд 8 — Що отримує студент після курсу
**Навички:**
- Full-stack розробка (React / Express / React Native)
- Робота з реальним API та клієнт-серверною взаємодією
- TypeScript, Redux, REST API, JWT
- Робота з тікетами як у реальній компанії
- Git, npm, monorepo, сучасний інструментарій
- Prompt engineering та робота з AI
- Система обробки помилок, валідація, безпека
- Готовий проєкт у портфоліо

## Слайд 9 — Архітектура
**Діаграма backend-layers**
- Технічна глибина: Express → Sprint Router → Auth Middleware → Controllers → Services → Sequelize → SQLite
- Спринтовий роутинг — унікальне рішення (один сервер, 4 рівні API)
- Централізована обробка помилок (ApiError + ErrorHandlingMiddleware)
- Shared packages з подвійною збіркою (ESM + CJS)

## Слайд 10 — Актуальність у цифрах

- 82% розробників використовують AI-інструменти щоденно (GitHub Developer Survey 2025)
- Середня зарплата full-stack в Україні: $3500-5500/міс (DOU 2026)
- Вартість ментора: $50-100/год. Розумна IDE з платформою: безкоштовно, 24/7

## Слайд 11 — Демо: E2E виконання задачі студентом
**Живий показ повного циклу роботи студента в розумній IDE:**

1. **Відкриття workspace:**
   - Відкриваємо IDE (Kiro/Cursor) з двома папками: платформа + проєкт студента
   - AI автоматично зчитує контекст

2. **Запуск інфраструктури:**
   - Просимо AI: "Запусти backend проєкту"
   - AI виконує команду, backend стартує на :4000

3. **Отримання задачі:**
   - Просимо AI: "Дай мені першу задачу Sprint 1 для frontend"
   - AI виводить тікет: "Sign Up Page Markup" з описом, сценаріями, посиланням на дизайн

4. **Робота над задачею:**
   - Просимо AI: "Поясни що мені потрібно зробити"
   - AI пояснює підхід: створити React-компонент, додати форму, реалізувати валідацію
   - Студент пише код, AI підказує якщо застряг

5. **Перевірка якості:**
   - Просимо AI: "Оціни мій код"
   - AI аналізує: структура, naming, обробка помилок, відповідність тікету
   - Дає рекомендації щодо покращення

6. **Перехід до наступної задачі:**
   - Просимо AI: "Яка наступна задача?"
   - AI видає наступний тікет з Sprint 1

**Висновок демо:** весь процес навчання відбувається в одному вікні IDE. AI — опціональний, але дуже зручний помічник.

## Фішки для захисту

1. **Почни з питання:** "Уявіть: ви хочете навчитись frontend. Де взяти працюючий backend щоб писати під нього?"

2. **Живе демо** — найсильніший момент. Покажи повний цикл у розумній IDE: AI запускає проєкт → видає задачу → допомагає → оцінює код.

3. **Порівняння:** "Ментор — $50/год, 2 години на день. Розумна IDE з нашою платформою — безкоштовно, 24/7, знає весь код."

4. **Про спринти:** "Це не абстрактні вправи. Авторизація, CRUD, пагінація — це те, що розробник робить кожен день на роботі."

5. **Результати тестування:** "Пілотне тестування показало 4.8 з 5 для корисності AI — студенти оцінили це вище за будь-який інший аспект платформи."

6. **Фінальна фраза:** "Продукт цієї роботи — не додаток для одного користувача. Це система, яка може навчити сотні студентів одночасно. А з розумними IDE — кожен отримує персонального ментора безкоштовно."

## Нотатки

- AI-асистент — це НЕ наш компонент. Це функціонал існуючих розумних IDE (Kiro, Cursor, Antigravity, Copilot)
- Наша платформа просто добре структурована для роботи з AI — код, тікети, документація в зрозумілому форматі
- Використання AI — опціонально. Платформа працює і без нього
- Monorepo — технічне рішення, не головний акцент. Бонус для просунутих студентів
- Головний акцент: готова інфраструктура + тікети з реальними продакшн-сценаріями
- Не згадувати EPAM External Lab
